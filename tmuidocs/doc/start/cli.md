##### 开发指南 tmui.design

### tmui-cli使用介绍

通过作者提供的命令行工具```tmui-cli```你将可以在本项目中自动更新、创建新的hbx cli项目或者hbx项目开始开发。

## 全局安装
请保证你的版本是1.2.8+

windows用户
```npm
npm -g install tmui-cli
tmui

```
mac ios

```npm
sudo npm -g install tmui-cli
sudo tmui
```

## 使用
请在项目文件的根目录下执行命令
```tmui```
将会打开一个可视化的升级页面，请按照提示操作即可。
