# 移动端设计系统规范

本规范是一套**通用移动端设计系统**：定义设计的「取值方式」与「档位体系」，保证跨页面、跨项目的风格一致性。不绑定具体产品、品牌色或组件实现。

## 核心原则

1. **体系优先于数值**：规范定义的是结构（色阶层级、字号阶梯、档位划分），具体品牌色可在每次设计任务开始前配置，但结构不可破坏。
2. **档位取值**：任何设计取值（色值、字号、圆角、阴影、间距）只能从规范档位中选择，**禁止使用档位外的自定义值**。
3. **双级配置**：品牌色组（主/深/浅底/渐变）为可配置参数；文本色阶、功能色、中性色、字号、圆角、阴影、间距为系统默认值，随品牌微调时不得破坏对比与层级关系。
4. **375px 画板**：移动端设计以 375px 宽、高度至少 814px（手机一屏）的画板为基准（对应 rpx 750，1px = 2rpx）；画板必须模拟顶部状态栏（时间、信号、电量等系统元素）。
5. **不绑定组件**：本规范只定义「看起来应该是什么」，不规定具体组件库实现。

## 使用流程（Penpot 设计时）

1. **设计前**：读取 [system.md](system.md) 获取完整系统定义；确认本次设计的品牌色组配置（优先读取 Penpot 令牌库，缺失时与用户确认或使用默认示例）。
2. **设计中**：所有取值从档位选择（见下），画板统一 375px 宽、高至少 814px，并模拟顶部状态栏；设计元素绑定令牌或严格使用令牌值。必须先制作并导出 1 个代表性画板作为视觉基线，确认文本、图标、间距和层级正常后再批量扩展。
3. **设计后**：按 [penpot-workflow.md](penpot-workflow.md) 的硬性约束与一致性检查清单逐项核对。必须逐页导出 PNG 进行肉眼视觉检查，同时执行文本高度、元素越界和画板完整性检查；任一画板未通过时禁止宣称完成或交付。

## 快速参照

### 色彩体系结构

```
品牌色组（可配置，示例见 system.md）
├── brand-main   主色      —— 主操作、选中态、链接
├── brand-dark   深色      —— 按下态、强调（主色降一档明度）
├── brand-hover  悬停色    —— 悬停态（主色提亮）
├── brand-soft   浅底      —— 标签底色、选中浅底（主色低饱和、高亮度）
└── brand-grad   渐变      —— 顶部品牌区背景（浅 → 深）

文本色阶（4 级固定层级）
├── 主文本      —— 标题、正文（深色，非纯黑）
├── 次级文本    —— 副标题、次级说明
├── 辅助文本    —— 占位符、弱化信息
└── 弱化/禁用   —— 禁用态、导航内分隔

功能色（4 组，每组 = 主色 + 浅底）
├── 成功 / 警告 / 错误 / 信息

中性色
├── 表面（白） / 页面背景（浅灰） / 输入框底 / 分隔线（页内 / 导航内）
```

### 字号阶梯（px，rpx = ×2）

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 大数字 | 46 | 700 |
| 首屏主标题 | 38 | 700 |
| 页首大标题 | 26 | 700 |
| 页面标题 | 24 | 700 |
| 区块标题 | 22 | 700 |
| 卡片标题 | 20 | 700 |
| 列表主标题 | 19 | 700 |
| 强调正文 | 17 | 600/700 |
| 列表项标题 | 16 | 700 |
| 区块小标题 | 15 | 600 |
| 正文（基准） | 14 | 400/600 |
| 辅助正文 | 13 | 400/600/700 |
| 说明/标签 | 12 | 400/600/700 |
| 角标 | 9 | 600 |
| 极小角标 | 8 | 400 |

行高：正文 1.4；紧凑（角标/标签）1.2；宽松 1.5–1.6。字重仅 400/500/600/700。

### 图标

统一使用 remix-icon 图标库（设计约束与布局实现通用），禁止使用字符或其他图标库冒充图标；图标默认 16px，名称从 remix-icon 库检索。Penpot 中每个可交付图标的顶层图层必须按正式资源名命名为 `icon / <remix-icon-name>`，例如 `icon / arrow-left-line`，禁止只写“返回”“用户”等中文语义名或 `svg-g`。同一页面或同一表单分组中的**同类型单行字段**必须采用一致的图标策略：若一个同级单行字段使用左侧语义图标，则该组其他同类型单行字段都必须补齐语义匹配、尺寸和颜色一致的图标，并统一图标位置、文字起点和间距。多行文本域属于不同控件类型，默认不加左侧图标，正文按顶部内边距对齐，不为追求形式一致强行添加图标。

### 圆角档位（px）

| 用途 | 值 |
| --- | --- |
| 大卡片 | 20 |
| 主按钮 | 16 |
| 输入框 | 14 |
| 次级卡片 | 13 |
| 小卡片/控件 | 12 |
| 小元素 | 8 |
| 标签 | 5 |
| 极小元素 | 3 |
| 头像/图标/胶囊 | 全圆 |

### 阴影档位

| 用途 | 值 |
| --- | --- |
| 白色卡片 | 纯黑 `#000000` @3%，X/Y `0 / 3px`，模糊 `12px`，扩散 `0` |
| 主按钮 | 元素主色 @32%，X/Y `0 / 6px`，模糊 `16px`，扩散 `0` |
| 底部弹层 | 中性深色 @7%，X/Y `0 / -4px`，模糊 `16px`，扩散 `0` |
| 聚焦/选中 | 元素主色 @12%，X/Y `0 / 0`，模糊 `6px`，扩散 `0` |

投影颜色跟随元素主色（红按钮 → 红色投影），不用黑/白；透明度、X/Y 偏移、模糊和扩散按档位固定。除非项目明确要求硬投影，否则禁止省略模糊参数或使用 `blur: 0`。

### 间距与尺寸（px）

| 项 | 值 |
| --- | --- |
| 页面左右边距 | 16 |
| 卡片内边距 | 20；紧凑卡片内容组必须整体垂直居中，上下视觉留白差不超过 1px |
| 输入框高度 | 58 |
| 主按钮高度 | 56 |
| 画板高度 | ≥ 814（手机一屏） |
| 分隔线 | 1px；连续 `cell`/信息条内部固定使用 `#F5F5F5` |

### 典型样式组合

- **卡片**：表面白底 + 圆角 20 + 纯黑 `#000000` 卡片阴影（X/Y/模糊 `0/3/12px`，3%，扩散 0）。
- **输入框**：高 58 + 圆角 14，默认使用 `bg-input`。位于白色卡片、面板或弹层内时必须使用 `#F5F7FB` 且常态无描边；只有直接位于浅灰页面背景、需要反向层级时才允许白底无描边。聚焦、错误、禁用状态按状态令牌增加描边。禁止不判断直接背景就选择填充或默认添加 `1px` 边框。完整连续表单不能全部只展示占位态，每个表单分组至少保留一个合理的预填充示例，同时保留其他字段空态，用于对比填写前后样式。
- **主按钮**：高 56 + 圆角 16 + 品牌主色底 + 白字 + 品牌主色投影（X/Y/模糊 `0/6/16px`，32%，扩散 0）。
- **顶部品牌区（hero）**：品牌渐变 + 白字；登录页高 360，列表页高 216。
- **页面**：浅灰背景，内容按 16px 边距排布。

## 从 Penpot 项目提炼的风格样本

以下规则来自对“智慧巡保 · 移动端设计稿 375”的只读分析，用作可复用的风格参考；它们不绑定该项目的业务页面、文案或信息架构。

- **产品气质**：企业内部作业工具，强调任务状态、进度、结果和下一步操作；界面克制、清晰、偏数据与流程，不使用营销型装饰。
- **主题机制**：支持按项目、角色或场景切换品牌主题。所有主题共享字体、字号、圆角、间距、页面结构和中性色，只替换品牌色组及其语义状态；样本项目中的具体色相不得作为后续项目默认值。
- **页面骨架**：375px 宽移动画板，顶部保留约 44px 系统状态栏；常见结构为状态栏、品牌/页面头部、任务内容区、操作区和底部导航。内容较长时按信息量纵向增长，不压缩首屏结构。
- **色彩关系**：页面以浅灰背景承托白色内容表面，主色只用于当前角色、主操作、选中态和关键进度；成功、警告、错误、信息使用独立语义色，不作为装饰色。主文本为深色而非纯黑，辅助文本逐级降低对比度。
- **信息层级**：页面标题和任务名称使用粗体；任务状态使用高识别度颜色和浅色状态底；时间、地点、负责人、说明等元信息使用较小字号和次级文本色；同一屏避免堆叠过多字号层级。
- **任务状态表达**：待完成、作业中、休息中、已完成等状态通过色彩、徽标、进度和主操作共同表达；主操作始终对应当前状态的唯一下一步，避免同级按钮竞争。
- **容器语言**：白色大卡片承载任务、统计和详情内容，使用明显圆角与柔和投影；卡片内部保持充足左右留白，列表信息按固定节奏排列。输入框、筛选和状态控件优先使用填充区分层级，描边只用于状态反馈。
- **操作语言**：主按钮使用主题色实底、白色文字和主题色柔和投影；次级操作使用低强调样式。拍照/扫码等高频动作使用明确的图标与大尺寸触控区域，图标不得用字符替代。
- **扫码取景框**：若四个角标已经明确取景范围，禁止再添加完整矩形描边形成重复边界。扫描光效不得使用单色实心横条，应采用横向“透明 → 品牌高亮色 → 透明”的渐变，可辅以同色柔和发光；渐变坐标必须位于元素内部。
- **导航语言**：底部导航固定承载主要模块，当前项使用主题色图标和文字，非当前项使用弱化中性色；导航与页面内容保持清晰边界，不额外堆叠装饰。
- **共用与角色页**：相机、个人信息、修改密码、关于应用等通用页面不重复制作角色主题结构；业务页通过主题令牌复用同一组件体系，保证不同色相主题的结构与视觉语言一致。
- **验收重点**：除结构和令牌检查外，必须重点检查主题色是否串色、状态是否可辨、主操作是否唯一、长页面信息节奏、卡片内部上下留白、底部导航当前态以及真实图标的可读性。
